# Nin-form

2D-платформер на Unity с тремя игровыми уровнями, системой сбора монет, ближней и дальней атакой и рандомизацией элементов третьего уровня.

Игра полностью проходима: после завершения третьего уровня появляется финальный экран.

![Обложка проекта](img/LevalGame1.png)

## 🎮 Игровой процесс

В проекте реализованы:

- **3 игровых уровня;**
- **движение персонажа:** ходьба, бег, прыжок и приседание;
- **две атаки:** ближняя атака и дальняя атака огненным шаром;
- **система здоровья:** получение урона и восстановление здоровья;
- **сбор монет и предметов;**
- **противники:** патрулирование, получение и нанесение урона;
- **выпадение предметов после победы над противниками;**
- **Parallax-фон;**
- **кат-сцены через Timeline;**
- **камера через Cinemachine;**
- **пауза и меню настроек;**
- **Tilemap для построения уровней;**
- **финальный экран после прохождения третьего уровня.**

## 🧩 Рандомизация третьего уровня

В третьем уровне используются заранее подготовленные игровые сегменты.

При запуске система случайным образом выбирает один из доступных вариантов и размещает его в сцене. Это позволяет менять отдельные части уровня между прохождениями без процедурной генерации геометрии.

## 👾 Противники

Для обычных противников реализованы:

- патрулирование между заданными точками;
- ожидание перед сменой направления;
- нанесение урона игроку;
- собственная система здоровья;
- смерть и выпадение предметов.

## 🛠️ Техническая информация

- **Движок:** Unity 2021.3.4f1
- **Язык:** C#
- **2D:** Physics 2D, Tilemap
- **UI:** Unity UI / TextMesh Pro
- **Камера:** Cinemachine
- **Кат-сцены:** Timeline
- **Рандомизация:** выбор заранее подготовленных игровых сегментов
- **Сохранение части пользовательских настроек:** PlayerPrefs

## 🎮 Управление

- **A / D или стрелки** — движение
- **Space** — прыжок
- **Left Shift** — бег
- **S** — приседание
- **ЛКМ** — ближняя атака
- **ПКМ** — дальняя атака

## 🚀 Запуск

### Для разработчиков

1. Клонировать репозиторий.
2. Открыть проект в Unity **2021.3.4f1**.
3. Запустить одну из игровых сцен проекта.

### Для тестирования

Готовую сборку можно запустить из папки `Build/`.
